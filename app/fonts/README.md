# Bundled fonts

These unmodified Latin variable WOFF2 files are the same Montserrat and Space
Grotesk assets previously downloaded by `next/font/google` in the successful
production build. They are now versioned and loaded through `next/font/local`
so building does not require the Google font resolver. CSS variable names and
the 500–700 weight range are preserved. Both families use the bundled SIL Open
Font License; upstream license sources are the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/montserrat
- https://github.com/google/fonts/tree/main/ofl/spacegrotesk

Source file provenance: generated CSS `.next/static/chunks/03rnfbktz0wz3.css`
in the successful local Next.js 16.3.8 build, identifying the Latin font faces.
The files are byte-for-byte copies with readable filenames.
